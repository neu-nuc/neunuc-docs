Architecture

NeuNuc is a hybrid Python + Node.js system designed to boot in under a second.

Python (port 8400) handles inference, memory, state, and orchestration via FastAPI.

Node.js (port 3400) serves HTML surfaces and proxies API calls.

Storage is flat JSON — no database to manage, no Docker swarm to debug.
