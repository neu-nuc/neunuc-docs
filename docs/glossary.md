# Glossary
Internal terminology and definitions.

| Term | Definition |
|------|------------|
| **Artifact** | A file produced during inference or pipeline execution, stored in `data/artifacts/`. |
| **Boot** | The startup sequence that initializes the runtime in 5 phases: Boot → Core → Orchestrate → Workloads → Surfaces. |
| **Broadcast** | Fire-and-forget message distribution to all connected WebSocket clients via `runtime/broadcast.py`. |
| **Bucket** | Token-bucket structure used by the Gate for per-IP rate limiting. |
| **Core** | The identity and health-check module (`runtime/core.py`). Tracks version, uptime, and system checks. |
| **DirectML** | Microsoft's hardware-acceleration API for ONNX on Windows GPUs. Set `DEVICE=directml` to use it. |
| **Gate** | The first line of defense (`gateway/gate.py`). Validates routes and enforces rate limits before a request hits a handler. |
| **Handler** | A function registered in `runtime/surface.py` that responds to an HTTP route. No classes — just functions. |
| **Inference** | Running a model to produce output from an input prompt. Performed by `inference/run.py` using ONNX Runtime. |
| **Memory** | Session-scoped JSON key/value storage (`runtime/store.py`). Persists to `data/memory/memory.json`. |
| **Mode** | Boot mode set via `--mode` or `MODE` env var. Common values: `api`, `cli`. Determines which surfaces are started. |
| **ONNX** | Open Neural Network Exchange. The model format NeuNuc uses for cross-platform inference. |
| **Orchestrator** | The workflow module (`runtime/orchestrator.py`) that chains inference steps, custom logic, and memory reads/writes. |
| **Phase** | One of the 5 boot stages. Each phase has a specific responsibility (e.g., Phase 4 loads models). |
| **Pipeline** | The ordered execution engine (`runtime/pipeline.py`). Runs steps in sequence and can halt early via `_stop`. |
| **Policy** | The rules engine (`runtime/rules.py`). Evaluates payloads against a ordered list of allow/deny rules. |
| **Prompt** | The input text sent to the inference endpoint. Subject to length and content validation. |
| **Request ID** | A 12-char hash generated by the Gate for every request. Used for tracing and debugging. |
| **Rule** | A dict in the rules engine with `name`, `match` lambda, `allow` boolean, and `reason` string. |
| **Runtime** | The running NeuNuc process. Includes boot, surface, pipeline, inference, and storage subsystems. |
| **Session** | A logical conversation or user context identified by `session_id`. Used to scope memory and state. |
| **SSE** | Server-Sent Events. Used by `/infer/stream` to push tokens to the client as they are generated. |
| **State** | Global JSON key/value storage (`runtime/store.py`). Persists to `data/state/state.json`. |
| **Step** | A single function in the inference pipeline (e.g., `validate`, `memory_inject`). |
| **Stop** | Pipeline halt flag (`_stop = True`). Prevents subsequent steps from running. |
| **Surface** | An HTTP/WebSocket interface exposed by the runtime. The main surface is FastAPI in `runtime/surface.py` with a Node.js bridge in `surface/server.js`. |
| **Token Bucket** | Rate-limiting algorithm where tokens replenish over time and each request consumes one token. |
| **Trace** | A Gate log entry containing request ID, timestamp, method, path, IP, and decision outcome. |
| **WS** | WebSocket. NeuNuc exposes `/ws` as a real-time broadcast channel for inference results. |
